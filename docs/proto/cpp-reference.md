# C++ reference

The [structured harness C++ reference](../api/proto_fuzzer/index.html) documents
the classes and functions under `proto_fuzzer/` for contributors. It includes
ownership and lifetime contracts, searchable symbols, and links to implementation
source. Generated protobuf types and dependency internals are outside its scope.

Doxygen renders the reference directly from the source. Function descriptions
live beside their definitions in `.cc` files; headers retain type and member
documentation. See [Development](../development.md#documentation) to build it
locally.
